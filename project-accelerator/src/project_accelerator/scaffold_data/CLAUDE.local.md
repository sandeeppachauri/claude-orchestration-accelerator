This file is gitignored — it is the machine-local counterpart to
`CLAUDE.md`. Use it for anything specific to your own machine or your own
in-progress work, never for anything the team needs to see.

- Tracked (`CLAUDE.md`): the entry-point shape, where config lives, how to
  run tests — true for every developer on every machine.

  login`, not committed here" — or a scratch note like "currently editing
  the `extract` step of `ticketClassification` in `process_registry.yaml`,
